Configurable Soroban / Abacus by makkuro on Thingiverse: https://www.thingiverse.com/thing:319514

Summary:
This is a configurable soroban / abacus. It prints in one go without any supports.  Note that it has to be turned around after printing for use (the feet will stick upwards to be printable)  The default soroban has 4 balls of value 1 and one ball of value 5 on each rod. It has 13 rods.   You can customize it as you wish using the customizer.  (I have yet to print this version. This is an extended version of the "Abacus for the board game Tikal", which prints nicely.)
